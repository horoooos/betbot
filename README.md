# ⚽ BetBot — бесплатный самообучающийся бот прогнозов

Работает 24/7 на GitHub Actions бесплатно, сервер не нужен.

## Что публикует в канал
| Пост | Когда |
|---|---|
| 📊 Статистика бота за вчера, 7 дней, 30 дней и всё время | каждое утро, ~08:10 МСК |
| 📅 Расписание матчей на день по лигам, с фаворитами | сразу после статистики |
| 🖼 Картинка матча (логотипы, цвета клубов, время, вероятности) + основной и смелый прогноз | примерно за час до каждого матча |
| 🔎 Полный разбор в ответе: таблица, форма, личные встречи, составы, xG, вероятные счета, все рынки, вывод | вместе с картинкой |
| 🏁 Итог в ответе к прогнозу: счёт, голы, удаления, статистика, ✅/❌ по каждому прогнозу, результат за день | после финального свистка |

**Рынки:** исход, двойной шанс, обе забьют, тоталы 1.5/2.5/3.5, индивидуальные тоталы, форы ±1.5,
точный счёт. Все они считаются из одной модели голов, поэтому друг другу не противоречат.

**Лиги с обзорами** (`REVIEW_LEAGUES` в `run.py`): АПЛ, Ла Лига, Серия A, Бундеслига, Лига 1, РПЛ,
Лига чемпионов, Лига Европы, Лига конференций, Эредивизи, Примейра, Суперлига Турции.
Можно добавить любые из `betbot/leagues.py`, но тогда постов будет больше.

## Как это работает
1. Из коэффициентов букмекеров (среднее по 40+ конторам с football-data.co.uk или DraftKings через ESPN)
   бот восстанавливает ожидаемые голы каждой команды. Из них строится матрица вероятностей всех счетов
   и считаются все рынки.
2. Своя модель силы команд (атака/оборона по истории 38 лиг) переобучается каждый день. Бот сам решает,
   какой вес ей дать против рынка, по точности прогнозов на последних двух годах. Сейчас вес 0%: рынок точнее.
3. Факторы для разбора (таблица, форма, личные встречи, составы, итоговая статистика) берутся с ESPN.
4. Русские названия команд — из Wikidata (кэш в `data/names_ru.json`), имена игроков — транслитерация.
5. Картинка рисуется сама (Pillow + шрифт Montserrat, лицензия OFL), логотипы — с ESPN.

## Файлы
- `run.py` — один запуск бота, все настройки сверху
- `betbot/espn.py` — расписание, коэффициенты, таблица, форма, составы, итоги
- `betbot/markets.py` — все рынки ставок из модели голов
- `betbot/texts.py` — тексты постов
- `betbot/card.py` — картинка матча
- `betbot/names.py` — русские названия
- `betbot/model.py`, `engine.py`, `data.py` — своя модель и её ежедневное обучение
- `data/results.csv` — история всех прогнозов и результатов (из неё считается статистика)

## Локально
```
pip install -r requirements.txt
python run.py        # без TELEGRAM_TOKEN посты сохраняются в data/preview/
python backtest.py   # проверка модели на прошлых сезонах
```

## Как бот работает 24/7 бесплатно
Репозиторий публичный, поэтому минуты GitHub Actions безлимитные. Одна задача крутится около 5,5 часа и запускает
бота каждые 5 минут (`LOOP_MINUTES`), а в конце сама запускает следующую. От расписания GitHub бот
не зависит. Расписание раз в 2 часа — только страховка, если цепочка оборвётся.

Остановить бота: *Actions → BetBot → «…» → Disable workflow*. Запустить снова: *Enable workflow → Run workflow*.
Токен бота хранится в секретах репозитория, в коде его нет и он никому не виден.

## Честно
Букмекеров стабильно обыгрывают очень немногие. Основной прогноз — это самый вероятный исход, а не
гарантированная прибыль. Смотри на статистику бота в канале минимум месяц, прежде чем ставить реальные деньги.
