# ⚽ BetBot — бесплатный самообучающийся бот прогнозов

Каждый день бот сам:
1. скачивает свежие результаты топ-5 лиг (football-data.co.uk, без ключей);
2. **переобучается**: обновляет силу атаки и обороны каждой команды и заново решает, насколько верить своей модели, а насколько рынку;
3. считает вероятности П1/Х/П2 и ожидаемые голы (xG) на ближайшие матчи;
4. ищет value-ставки (наша вероятность × лучший коэффициент > 1.05);
5. шлёт всё в Telegram;
6. записывает каждый прогноз в `data/picks.csv` и после матча честно считает итог (ROI).

Всё работает бесплатно на GitHub Actions, свой сервер не нужен.

## Запуск за 10 минут

### 1. Создай бота и канал в Telegram
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.
2. Создай канал (или группу) и добавь бота туда администратором.
3. Узнай **chat_id**: для публичного канала это `@имя_канала`. Для личного чата напиши боту что угодно и открой
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, там будет `"chat":{"id":...}`.

### 2. Залей проект на GitHub
1. Зарегистрируйся на github.com и создай **публичный** репозиторий: для публичных Actions бесплатны без ограничений.
2. Загрузи туда все файлы этой папки (кнопка *Add file → Upload files*).

### 3. Добавь секреты
*Settings → Secrets and variables → Actions → New repository secret*:
- `TELEGRAM_TOKEN` — токен от BotFather
- `TELEGRAM_CHAT_ID` — id или `@имя_канала`

### 4. Запусти
*Actions → Daily predictions → Run workflow*. Через минуту придёт сообщение. Дальше бот будет запускаться сам каждый день в 10:00 МСК.

## Локально
```
pip install -r requirements.txt
python backtest.py     # проверка на прошлых сезонах
python run_daily.py    # прогноз на сегодня (без токена печатает в консоль)
```

## Честно о результатах (бэктест 2021–2026, 5 лиг, ~9000 матчей)
- Чистая модель Пуассона немного **уступает** рынку по точности (log-loss 0.990 против 0.970).
  Поэтому система сама снижает её вес до нуля. Это и есть обучение: она не притворяется умнее букмекеров.
- Ставки по лучшему коэффициенту выше справедливой цены Pinnacle дали около +4% на 900 ставках,
  но по сезонам результат скачет от −12% до +15%. Это ещё **не доказанный** плюс. К тому же лучшие коэффициенты
  на практике быстро уходят, а выигрывающим игрокам букмекеры режут лимиты.
- Пару месяцев смотри на статистику бота «на бумаге» и только потом решай, ставить ли реальные деньги.

## Что можно улучшить
- Добавить в модель составы, травмы и xG из реальных матчей (например, understat).
- Добавить больше лиг (в `betbot/data.py` → `LEAGUES`: `E1`, `N1`, `P1`, `T1`…).
- Добавить азиатские форы: в данных уже есть колонки `AvgAHH` и `AvgAHA`.
