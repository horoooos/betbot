# ⚽ BetBot — бесплатный самообучающийся бот прогнозов

Работает 24/7 на GitHub Actions: запускается каждые 30 минут, сервер не нужен, всё бесплатно.

**38 лиг**: топ-5 Европы, их вторые дивизионы, Нидерланды, Португалия, Турция, Бельгия, Греция,
Шотландия, низшие лиги Англии, а также Бразилия, Аргентина, MLS, Мексика, Япония, Китай, Скандинавия,
Австрия, Швейцария, Польша, Румыния, Россия, Ирландия. На табло дополнительно еврокубки.

## Что публикует в канал
| Пост | Когда |
|---|---|
| 🏆 Карточки прогнозов по лиге: вероятности П1/Х/П2 со шкалами, xG, вероятный счёт, ТБ 2.5, 💎 value | за ≤ 36 часов до матча, каждый матч один раз |
| 📺 Закреплённое LIVE-табло: счёт и минута всех матчей дня, ✅/❌ угадал ли бот | обновляется каждые 30 минут (одно сообщение, без спама) |
| 📊 Итоги value-ставок и общая статистика (ROI) | раз в день |

## Как бот учится
Раз в сутки он скачивает свежие результаты, пересчитывает силу атаки и обороны каждой команды
(свежие матчи весят больше) и заново решает, насколько верить своей модели, а насколько рынку.
Для этого он проверяет себя на последних двух годах матчей.

## Источники данных (бесплатно, без ключей)
- [football-data.co.uk](https://www.football-data.co.uk): результаты и коэффициенты
- ESPN (открытый API): live-счёт

## Честно о результатах
- Модель сама по себе немного уступает рынку, поэтому вес модели сейчас 0%. Вероятности в постах — это
  оценка рынка без маржи букмекера, а xG и вероятный счёт берутся из модели.
- Value П1/Х/П2 по лучшему коэффициенту на истории давали +3…12% в год. Но на практике лучший коэффициент
  быстро исчезает, а выигрывающим игрокам режут лимиты.
- Value на тоталы на истории были в минусе (−3…−10%), поэтому они отключены, пока модель не докажет обратное.
- Смотри на статистику в канале «на бумаге» хотя бы пару месяцев.

## Лимиты бесплатного GitHub
Приватный репозиторий: 2000 минут в месяц, бот тратит около 1500. Если сделать репозиторий публичным,
минуты станут безлимитными и можно поставить запуск каждые 10–15 минут (`cron` в `.github/workflows/daily.yml`).
