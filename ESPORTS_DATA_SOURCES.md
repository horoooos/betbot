# Бесплатные данные и оригинальное окружение Dota / CS2

Проверено 20 ноября 2026. Платные API и подписки не подключались.

## Что подключено

Valve dota2.com/webapi/IDOTA2League/GetLiveGames/v001 и IDOTA2MatchStats/GetRealtimeStats/v001: живые матчи, координаты героев, уровень, KDA, золото, предметы и ID способностей. При повторной проверке реального ответа поля healthpoints/maxhealthpoints, mana и cooldown отсутствовали. Не заполняем их выдуманными значениями.

Оригинальные геометрия земли, модели зданий и деревья экспортированы из установленной Dota 2 официальным открытым инструментом Source 2 Viewer 21.1: https://s2v.app/ValveResourceFormat/guides/exporting-models.html . Игра и её файлы не изменялись. Права на игровые материалы остаются у Valve. Геометрия и текстуры обслуживаются нашим GitHub Pages, без чужого игрового CDN.

Подготовка: tools/prepare_dota_environment.py обрабатывает локальные glTF-экспорты в work/dota-ground и work/dota-export, уменьшает текстуры до 512 px, исключает лишние vertex-атрибуты и запекает поле высот из треугольников земли. Деревья извлекаются из ent_dota_tree карты; это начальные статические позиции, не текущая информация об уничтожении деревьев. Исходный и оптимизированный экспорт разделены.

Калибровка по двум Древним карты и живому кадру: worldX = x * 20416; worldY = y * 20928 - 256. После VRF glTF экспорта worldX = -Z / 0.0254, worldY = X / 0.0254. Размеры зданий и героев адаптированы для читаемости тактического просмотра, а не для физической симуляции.

## Дополнительные кандидаты

- PandaScore free: расписание, результаты, составы, ссылки вещателей. Подробные live frames и события отсутствуют в бесплатном плане: https://developers.pandascore.co/docs/plan-reference .
- GRID Open Access: требуется одобренный доступ; Series Events не включён. Нельзя считать его готовым безлимитным потоком координат всех матчей: https://grid.gg/open-access/ .
- Cito API: 500 бесплатных запросов в месяц, задержка 60 секунд; live-состояние CS2 не содержит координат. Позиционные события — для завершённых карт: https://www.citoapi.com/docs/api/cs2/live/ .
- OpenDota: полезен для истории, результатов и анализа реплеев. Не найдено подтверждённого полного live entity feed с HP, заклинаниями и крипами: https://docs.opendota.com/ .
- Valve Game State Integration: бесплатная телеметрия наблюдаемого матча из работающего игрового клиента. Требует наблюдателя; не является удалённым API любых турниров: https://github.com/antonpup/CounterStrike2GSI .
- CSTV HTTP broadcast + DemoFile.Net: бесплатный открытый парсер способен читать живые CS2 entities, координаты и события. Нужен доступный разрешённый адрес CSTV конкретного матча; универсальный открытый адрес всех профессиональных матчей не найден: https://github.com/saul/demofile-net .
- datdota/broodmother: открытый клиент, но его публичный backend запрещает подключение конкурирующего/заменяющего интерфейса. Backend и CDN не используются: https://github.com/datdota/broodmother/blob/main/TERMS.md .

## Проверка изменений

browser-check.yml запускает Google Chrome на GitHub runner. Записанные реальные кадры Valve используются только как управляемая тестовая последовательность; на сайте живые кадры не заменяются реплеем. Проверки требуют загрузки оригинального рельефа, деревьев, моделей, изменения поз скелета и конечной высоты над землёй. Скриншоты и report.json сохраняются в browser-proof.
