# Правила работы над betbot

1. **Перед любой правкой — проверить всю структуру:** `python tools/check_structure.py`
   (ветка, дерево, обязательные файлы, компиляция всех модулей, свежесть данных, грязное дерево).
   Работаем в ветке `dev`; в `main` попадает только проверенное — бот берёт код из `main`.
2. **Каждое изменение — скриншот и проверка «работает».**
   - карточки: отрендерить PNG и посмотреть глазами;
   - сайт: headless Chrome, снимок с обходом кэша (`?v=timestamp`) и ожиданием JS (`--virtual-time-budget`);
   - если на снимке не то — править, пока не станет рабочим, и только потом отчитываться.
3. **Перед новой карточкой для «захода ставки» — спросить владельца «ок или нет»** и показывать варианты, пока не понравится.
4. **Никаких «должно работать»** — только фактическая проверка.
