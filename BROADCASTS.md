# Поиск прямых трансляций

`betbot/broadcasts.py` ищет источники видео отдельно от прогнозирования. Не требует,
чтобы бот поставил на матч. Поддерживаемые виды: футбол, хоккей, баскетбол, теннис,
CS2 и Dota 2. Список каналов: `data/broadcast_sources.json`.

Источники:

- PandaScore: `running` и `upcoming`, все уровни турниров. Сохраняем `streams_list`,
  `official_stream_url`, старые `english`/`russian.raw_url`. Это ссылки конкретного
  события, но не независимое подтверждение, что канал сейчас показывает этот матч.
- Официальные YouTube-каналы: вкладка прямых эфиров, действительный LIVE badge,
  затем отдельная проверка `isLiveNow` на странице видео. Заголовок со словом LIVE
  сам по себе не считается подтверждением. Записи, повторы и обзоры исключаются.
- ESPN: только ссылки `rel=watch` в метаданных события, без видеообзоров. Подписку
  или доступность в регионе не предполагаем. Недоступные ответы видны в отчёте.

Для сопоставления нужны оба участника; используются исходные и русские имена,
границы слов и время матча. Неоднозначные сокращения не привязываем по догадке.
Доступные карты Valve тоже входят в поиск. Новый эфир официального канала с явно
названной парой участников сохраняется даже без матча в нашем расписании.

## Запуск

`python tools/broadcast_scan.py` — проверка с локальными расписаниями, без записи
в облако; отчёт `work/broadcasts-check.json`. `--remote` загружает свежий список
матчей из main. `--publish` требует `FIREBASE_SA` и записывает публичный результат
в отдельную ветку Firebase `/broadcasts`; остальные правила не заменяются,
публичная запись запрещена. `PANDASCORE_TOKEN` нужен только для PandaScore.

Workflow `broadcast-scan.yml` запускается по cron каждые 5 минут и вручную.
GitHub может задерживать cron; это не гарантия непрерывной работы. Отчёт доступен
в артефакте запуска. `probe=true` выводит только публичные заголовки и признаки
YouTube-карточек для диагностики различий выдачи.

Веб-страница `docs/broadcasts.html` читает результаты раз в минуту и убирает
истёкшие ссылки. `live` = подтверждённый на момент проверки YouTube-эфир (10 минут
срока); `listed` = ссылка из карточки события (15 минут). При отсутствии новых
данных время проверки не обновляется. Сайт показывает источник, статус и условия
доступа; пользователь открывает плеер вещателя.

Это поиск по подключённым источникам, не индекс всего Интернета. Некоторые матчи
вообще не имеют общедоступного видео. Географические ограничения, авторизацию и
платный доступ не обходим. Видео не скачиваем и не ретранслируем. Платные сервисы
не подключены; действуют обычные квоты GitHub, Firebase и поставщиков данных.

Переключатель 3D/видео в самих трекерах и дополнительная независимая проверка
Twitch — отдельные следующие изменения. Этот модуль предоставляет для них
реестр ссылок, сроки действия и доказательства сопоставления.
